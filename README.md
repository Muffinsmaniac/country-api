Country API

Prerequisites:
-Java 17 or higher

To run the program:

1. Clone the repository:
https://github.com/Muffinsmaniac/country-api

2. Navigate to project folder.

3. Build and run the application by running this command in the Command Terminal:
mvnw.cmd spring-boot:run

4.Navigate to:
http://localhost:8080

5. Browse countries, filter by regions, make notes etc
